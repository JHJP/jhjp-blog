# Current workout routine
> Concept: lazy workout which focused on sustainability.

## Cardio Framework
`Walk 1.5km + Workout + Walk 1.5km` -> `Walk 3km (Rest Day)` -> `Repeat alternating A and B`.

### Workout A: Pull & Quad Focus
1. Squat: 3 sets to failure (Target: 8+ reps at 75kg)
- Targets: Quads, Glutes, Abs
2. Cable Seated Row: 3 sets to failure (Target: 8+ reps at 52kg)
- Targets: Upper Back, Lats
3. Hanging Knee Raise: 3 sets to failure (Target: 8+ reps)
- Targets: Abs
4. Barbell Curl: 3 sets to failure
- Targets: Biceps (Balances out the heavy tricep work in Workout B).

### Workout B: Push & Hamstring Focus
1. Push Up: 3 sets to failure (Target: 20/15/12)
- Targets: Chest, Triceps, Front Delts
2. Barbell Shoulder Press: 3 sets to failure (Target: 8+ reps at 30kg)
- Targets: Front Shoulders, Triceps, Abs
3. Lat Pulldown: 3 sets to failure (Target: 8+ reps at 52kg)
- Targets: Lats, Back
4. Dumbbell Romanian Deadlift: 3 sets to failure
- Targets: Hamstrings, Glutes

> **Execution Note:**
If you complete your final set of an exercise and find you can do more reps than you did in your very first set, you are not pushing hard enough. Treat every set as a mental battle to drive growth.
